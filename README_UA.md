# Онлайн-газета — стартовий шаблон (українською)

Це демонстраційний стартовий проєкт новинного сайту з:
- публічною головною сторінкою;
- малопомітною кнопкою входу редактора у верхній панелі;
- логіном і паролем, які задаються через змінні середовища;
- створенням, редагуванням і видаленням статей;
- завантаженням текстових файлів і зображень;
- формою для вставлення посилання на джерело.

**Це незалежний демонстраційний шаблон, а не офіційний сайт ТСН чи 1+1 media.** Перед публікацією використовуйте лише логотипи, фотографії й тексти, на які маєте право.

## Запуск локально

1. Установи Node.js 18 або новішої версії.
2. Розпакуй ZIP.
3. Відкрий термінал у папці проєкту.
4. Виконай:
   ```bash
   npm install
   ```
5. Задай змінні середовища:
   - `ADMIN_USER` — логін редактора (наприклад, `editor`)
   - `ADMIN_PASSWORD` — довгий унікальний пароль
   - `SESSION_SECRET` — довгий випадковий секрет для сесій
   - `PORT` — необов'язково; зазвичай хостинг задає його сам
6. Запусти:
   ```bash
   npm start
   ```
7. Відкрий `http://localhost:3000`.

У PowerShell можна задати змінні для поточного вікна так:
```powershell
$env:ADMIN_USER="editor"
$env:ADMIN_PASSWORD="ВСТАВ_СВІЙ_ДОВГИЙ_ПАРОЛЬ"
$env:SESSION_SECRET="ВСТАВ_ДОВГИЙ_ВИПАДКОВИЙ_СЕКРЕТ"
npm start
```
Не використовуй наведені приклади як справжній пароль. Не записуй секрети в код або GitHub.

## Розміщення на Bot-Hosting.net

1. Створи Node.js-сервер/проєкт у панелі хостингу.
2. Завантаж файли з ZIP або підключи приватний GitHub-репозиторій.
3. Команда запуску: `npm start`.
4. Додай у Environment Variables:
   - `ADMIN_USER`
   - `ADMIN_PASSWORD`
   - `SESSION_SECRET`
   - `NODE_ENV=production`
5. Перезапусти сервіс і відкрий надану хостингом адресу.

Назви пунктів у панелі хостингу можуть відрізнятися. Переконайся, що сервіс має HTTPS, і не публікуй паролі в чатах чи репозиторії.

## Важливі обмеження стартової версії

- Статті зберігаються в `data/articles.json`, завантажені файли — у `public/uploads`. На хостингах із тимчасовою файловою системою вони можуть зникнути після перезапуску/перерозгортання. Для постійного зберігання підключи постійний диск або базу даних.
- Цей проєкт **не синхронізує зміни статей у GitHub автоматично**. Він зберігає їх на сервері. Для GitHub-синхронізації потрібне окреме безпечне підключення GitHub API.
- Імпорт за посиланням лише перевіряє URL і показує підказку. Автоматичне завантаження довільних вебсторінок вимкнене з міркувань безпеки та прав на контент.
- Підтримка імпорту файлів у цій версії: `.txt`, `.md`, `.html`, `.htm`; зображення `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`. DOCX наразі не підтримується.
- Для серйозного публічного запуску потрібні додаткові заходи: обмеження спроб входу, CSRF-захист, резервне копіювання, постійне сховище, перевірка типів файлів та обмеження прав доступу.

## Структура

- `server.js` — сервер і API
- `public/index.html` — головна сторінка
- `public/style.css` — оформлення
- `public/app.js` — завантаження статей і редакторська панель
- `data/articles.json` — статті
- `public/uploads/` — завантажені файли
